뷰티.트렌드

안내

이 사이트는

올리브영 뷰티 브랜드의 관심이 평소보다 얼마나 올랐는지 매일 점수로 보여 주는 개인 프로젝트예요. 점수 100이 평소예요.

자료 출처

  • 네이버 데이터랩의 검색어 트렌드와 쇼핑인사이트. 네이버가 준 값은 그대로 싣지 않고 "평소의 몇 배"로 바꿔 보여 줘요.
  • 올리브영과 에이블리의 판매 순위.
  • YouTube. 브랜드 이름으로 찾은 영상의 제목과 링크예요.

YouTube 자료

이 사이트는 YouTube API Services로 영상 제목과 링크를 받아 와요. 받은 자료는 28일이 지나면 지우고, 점수 계산에는 쓰지 않아요.

YouTube 영상 링크를 쓰면 YouTube 서비스 약관에 동의하는 것으로 봐요. Google이 정보를 다루는 방식은 Google 개인정보처리방침에 있어요.

개인정보처리방침

이 사이트는 방문자의 개인정보를 받거나 저장하지 않아요. 로그인, 쿠키, 방문 기록 분석 도구가 없어요.

  • 사이트 파일은 GitHub Pages가 보내 줘요. GitHub이 접속 기록(IP 주소 등)을 남길 수 있고, 그 내용은 GitHub 개인정보처리방침을 따라요.
  • 글꼴은 jsDelivr에서 불러와요.
  • 네이버, YouTube, 올리브영, 에이블리 링크를 누르면 그 서비스의 방침이 적용돼요.
